One machine

The homelab is my old gaming PC, wiped and running Proxmox VE. The graphics card that used to run games now runs language models, so as you scroll it heats up the way it does in my Grafana dashboard.

  • Proxmox VE as the host
  • GPU shared into a container for AI work
  • Managed from my phone or Mac over Tailscale

Split into layers

Proxmox splits the machine into a virtual machine for apps and a lightweight container for AI. The VM runs every app with Docker Compose. The container gets the GPU and runs Ollama, which the apps call for anything that needs a model.

What runs on the docker VM:

  • Fuel my calorie tracker
  • Forgejo Git server
  • Grafana dashboards
  • InfluxDB metrics
  • Uptime Kuma status checks
  • n8n automations
  • Open WebUI chat with local models
  • AdGuard Home DNS ad-blocking
  • Jellyfin my media
  • Syncthing file sync
  • ntfy phone alerts
  • Caddy HTTPS
  • Homepage start page
  • Dockge stack manager

Run like production

It’s one PC, but I run it the way a team runs real infrastructure, because that’s the habit I want to practise.

Everything in Git
Self-hosted Forgejo with a protected main branch. Every change goes through a pull request, and the repo mirrors to GitHub.
HTTPS on every app
Caddy with a Let’s Encrypt wildcard certificate, issued through a Cloudflare DNS challenge.
Nothing exposed
Apps are only reachable over Tailscale, from my own devices.
Backups I’ve restored
Nightly encrypted restic backups to Backblaze B2, with a tested restore.
Monitoring and alerts
Grafana and InfluxDB, including GPU temperature, power and memory; Uptime Kuma checks; alerts to my phone through ntfy.
Infrastructure as code
Terraform with the Proxmox provider to create machines from a file instead of by hand.
Automations
An n8n morning briefing and a news digest written by the local model, delivered to my phone.

Projects

Fuel

A calorie tracker I built for myself, running on the homelab.

  • Type “5 egg whites and 40 g oats” or take a photo: a local model on my GPU works out what and how much, and USDA data supplies the nutrition.
  • Barcode scanning in iPhone Safari with a WebAssembly reader, plus Open Food Facts lookups.
  • Adaptive targets that estimate real energy burn from logged intake and the weight trend.

FastAPI, SQLite, JavaScript, Ollama, Docker. 31 automated tests.

The code lives in my private homelab repo. I’m happy to walk through it.

NetDevOps Lab

A campus network defined entirely as code, built while studying for the CCNA.

  • Two redundant core switches running OSPF and VRRP, VLANs for users and servers, all on Arista cEOS in Containerlab.
  • An inventory file is the source of truth: Jinja2 renders the config, NAPALM deploys it, pytest proves the network works.
  • Drift detection, and a local LLM that answers questions about the live network in plain English.

Python, Nornir, Jinja2, NAPALM, pytest, Containerlab, GitHub Actions.

AI Car Dealer

A local tool that reads a used-car listing and tells you whether it’s a deal.

  • Scores the listing, flags scam signs and missing details, and drafts the first message to the seller.
  • Structured output from a local model with Instructor and Pydantic, so the result is typed data, not loose text.
  • Checks the VIN’s checksum offline and catches typo’d or fake VINs.

Python, Ollama with Gemma 3, Instructor, Pydantic, Crawl4AI, PostgreSQL, Docker Compose.
