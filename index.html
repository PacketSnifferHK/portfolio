Things I’ve built

Runs on the homelab

Fuel

A calorie tracker I built for myself, with the AI running on my own GPU.

  • Type “5 egg whites and 40 g oats” or snap a photo; a local model works out what and how much, and USDA data supplies the nutrition.
  • Live barcode scanning in iPhone Safari through a WebAssembly reader.
  • Targets that adapt: it estimates real energy burn from logged intake and the weight trend.

FastAPI, SQLite, JavaScript, Ollama, Docker. 31 automated tests.

Private repo, happy to walk you through it.

Network automation

NetDevOps Lab

A campus network defined entirely as code, built while studying for the CCNA.

  • Two redundant core switches with OSPF and VRRP, VLANs for users and servers, on Arista cEOS in Containerlab.
  • One inventory file is the source of truth: Jinja2 renders configs, NAPALM deploys them, pytest proves it works.
  • Drift detection, plus a local LLM that answers questions about the live network.

Python, Nornir, Jinja2, NAPALM, pytest, Containerlab, GitHub Actions.

Local AI

AI Car Dealer

Reads a used-car listing and tells you whether it’s a deal, all offline.

  • Scores the listing, flags scam signs and missing details, and drafts the first message to the seller.
  • Typed output from a local model with Instructor and Pydantic, not loose text.
  • Checks the VIN’s checksum offline to catch typos and fakes.

Python, Ollama with Gemma 3, Instructor, Pydantic, Crawl4AI, PostgreSQL, Docker Compose.
